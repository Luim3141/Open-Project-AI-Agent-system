Develop Mini Task Manager Application
**Project Objective**

Develop a functional Mini Task Manager web application using an automated multi-agent software development workflow.

**Technology Stack**

*   Backend: Python FastAPI
    
*   Database: SQLite
    
*   Frontend: HTML, CSS, JavaScript
    
*   Testing: pytest
    
*   Version Control: Git and GitHub
    

**Functional Requirements**

1.  Create new tasks.
    
2.  View a list of tasks.
    
3.  Edit task information.
    
4.  Delete tasks.
    
5.  Update task status.
    
6.  Search and filter tasks.
    
7.  Persist data in SQLite.
    
8.  Provide a usable web interface.
    

**AI Development Workflow**

The AI team should:

1.  Analyze requirements and define acceptance criteria.
    
2.  Break down the project into development tasks.
    
3.  Establish dependencies and propose a development schedule.
    
4.  Implement source code in the Git repository.
    
5.  Build and execute automated tests.
    
6.  Review the implementation and identify defects.
    
7.  Fix defects and rerun tests.
    
8.  Create Git commits and a Pull Request.
    
9.  Report development progress and verification evidence in OpenProject.

The application must run locally, support the required operations, pass automated tests, and have verifiable source code and development history.
