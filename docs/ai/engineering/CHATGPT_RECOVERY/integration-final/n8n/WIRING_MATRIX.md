The webhook-only workflows are intentional authenticated support actions, not orphaned automatic schedulers. Missing automatic Native/index/QA/GitHub publishers were real integration gaps; new branches address them while preserving existing human contracts. No redundant orchestration is added. MAIN classifications above use published definitions, exact serving source/image parity and matching durable receipts; they do not prove every branch. Full semantic and UI acceptance remain blocked.

Event identities contain source/project/version/event/timestamp/idempotency key and minimal metadata. Callback accepts only exact persisted canonical event plus fresh HMAC and numeric n8n execution ID. HeaderAuth protects transport; human Bearer/Origin/query are denied. Callback claim prevents concurrent duplicate business work; repair job identity includes event ID so crash replay does not rerun an already verified repair. Visibility tombstone is not physical-delete authority. WF04 retained data is deliberately projected by current image to canonical lifecycle fields; PR details remain in Gateway receipts and UI projection, not raw n8n prompts.
